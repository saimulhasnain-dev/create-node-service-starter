# {{name}}

Node.js + TypeScript + Express service, generated by `create-node-service-starter`.

## Run

```sh
cp .env.example .env
npm install
npm run dev        # watch mode on http://localhost:3000
npm test           # node:test
npm run build && npm start
```

## What is included

- `src/config.ts` validates env at startup and lists all problems at once.
- `src/app.ts` Express app: request ids, JSON request logs, `/health`, JSON 404 and error handler that hides 5xx internals.
- `src/server.ts` graceful shutdown on SIGTERM/SIGINT.
- `Dockerfile` multi-stage, non-root, with a healthcheck.
- Tests with `node:test` against a real server on a random port.
